# Deep Dive

Explore from the high sky to the deepest trench and discover animals by their silhouettes.

```bash
npm install
npm run dev        # play at http://localhost:5173
npm run check      # typecheck, unit tests, build, e2e
```

Controls: drag, scroll wheel, arrow keys / W,S, or the slider on the right. Tap a silhouette to discover it.
See `CLAUDE.md` for the architecture and how to add species.
